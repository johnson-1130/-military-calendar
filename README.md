# Military Calendar

這是一個記錄我 2026 年 10 月 12 日於台中成功嶺入伍後，直到退伍前的重要日期與準備事項的單頁網站。

網站內容包含：

- 入伍與退伍日期估算
- 新訓與後續訓練的大致時間軸
- 10 月到 1 月行事曆
- 成功嶺期間的台中氣溫參考
- 入伍前注意事項
- 可勾選的行李與文件準備清單
- 軍訓折抵 5 天的相關提醒

## Website

GitHub Pages 部署完成後，可透過以下網址查看：

`https://johnson-1130.github.io/-military-calendar/`

## Note

本網站內容主要作為個人入伍前規劃與行程整理使用。

實際放假、撥交、結訓與退伍日期，仍以國防部、役政單位及部隊正式公告為準。
